# Verifly Roadmap

## Phase 1: Foundation & Auth (Weeks 1-3)
- User signup/login/logout with JWT
- Hamburger navigation shell
- Database schema (users, airlines, reviews)
- Profile pages

## Phase 2: Review System (Weeks 4-6)
- Browse Nigerian airlines
- Submit reviews with star ratings
- Ticket ID field required
- Flag system for disputes

## Phase 3: Ticket Verification (Weeks 7-10)
- Manual admin verification pipeline
- Verified badge on reviews
- Airline API integration ready
- Appeals flow

## Phase 4: Airline Partnership (Month 4+)
- Partner portal for airline responses
- Direct API for ticket data
- Analytics dashboard
- Revenue model (3 tiers)
